# AuraRush

Marketing site for AuraRush, a UK IT services and IT consulting business. Built with Next.js (App Router), React, and TypeScript.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Checks

```bash
npm run lint
```
